# Google Workspace MCP v1.1.0

- Create Google Docs with reviewed content; read, append and replace document text.
- Create Drive folders, upload text, move files, share files and move files to Trash.
- Create Sheets and read/write/append literal cell values.
- Create and read Slides presentations and append title/body slides.
- Update Calendar events; edit and complete Tasks. Explicit confirmation is required for deletion and sharing.
- New OAuth scopes for Drive files, Sheets and Slides. Existing users must reconnect Google to grant the added permissions. Enable the corresponding APIs in the Google Cloud project.
- Report partial document/file creation without falsely claiming a successful upload.
